# Website and Training Module

A beginner-friendly, reproducible website development and teaching project using ChatGPT directly connected to GitHub, Cloudflare for deployment, and optional VS Code for local practice. **No Codex.**

## Two parallel tracks
- `website/`: application source and tests
- `training/`: lessons, slides, instructor guides and exercises

## Curriculum
00. Project orientation
01. First-time GitHub account and ChatGPT connection
02. Repository structure and safe collaboration
03. First-time Cloudflare account and GitHub connection
04. Niche discovery and lead capture (Google Maps research and compliant data collection)
05. Requirements and architecture
06. Environment and application setup
07. Public website
08. Admin panel and access controls
09. Database and APIs
10. Testing, security and accessibility
11. Production deployment and monitoring
12. Training delivery and independent recreation

## Completion rule
Each milestone needs tested output, documented dependencies and permissions, reproducible steps, screenshots or examples, troubleshooting, and learner assessment.

## Security
Never commit passwords, API tokens, private keys, or `.env` files. Use `.env.example` with placeholders and configure Cloudflare secrets separately.

See `project-management/roadmap.md` and `project-management/master-checklist.md`.
