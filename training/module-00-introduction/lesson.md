# Module 00 — Project orientation

**Objective:** Explain the two-track workflow: building a working website and creating reproducible training materials simultaneously.

## Learning outcomes
- Describe the ChatGPT → GitHub → Cloudflare workflow.
- Explain the role of VS Code as an optional local editor.
- Identify the training and website directories.
- Apply the milestone completion checklist.

## Exercise
Open the repository README and explain what each project directory is for.

## Verification
Learner can identify the repository, default branch, working branch, and project milestones.
