# Module 01 — Connect GitHub to ChatGPT (first-time users)

## Prerequisites
A GitHub account with verified email and access to ChatGPT.

## Procedure
1. Sign up at https://github.com/ and verify your email.
2. Enable two-factor authentication and store recovery codes safely.
3. Create a private repository with a descriptive name.
4. In ChatGPT, open Settings → Plugins (or the available apps/connector interface) and locate GitHub.
5. Choose Connect and follow the GitHub authorization screen. Review the requested repository access before approving.
6. Return to ChatGPT and provide the full repository URL.
7. Ask ChatGPT to inspect repository metadata and read an existing file to verify access.
8. For writes, ask ChatGPT to create a working branch and use pull requests for review.

Interface labels may differ by account or platform. Never paste personal access tokens into chat.

## Exercise
Verify read access and create a documentation branch.

## Troubleshooting
If access fails, check GitHub authorization, repository permissions, correct URL, and whether the repository is empty.
