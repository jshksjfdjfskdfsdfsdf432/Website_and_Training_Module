# Module 02 — Repository workflow

## Learning outcomes
Understand `main`, feature branches, commits, pull requests, and review.

## Practical steps
1. Inspect repository structure.
2. Create a branch for each milestone.
3. Make a small documentation change.
4. Open a pull request.
5. Review the diff and merge only after verification.

## Security
Keep credentials out of Git history. Use branch protection when appropriate.
