# Module 06 companion lesson — AI-first development

## Learning objective
Learn to request, review and validate software changes without manually writing most of the code.

## Guided exercise
1. Describe a small feature in ordinary language: “Show a business service catalogue with name and price label.”
2. Ask ChatGPT to inspect the GitHub repository, work on a feature branch and create a pull request.
3. Review the PR summary and compare it with the acceptance checks.
4. Check automated tests and identify any runtime tests still pending.
5. Approve or request changes; do not share secrets or deploy before review.
6. Record the feature request, PR URL, verification evidence and training lesson update.

## Example request
Implement an editable sample service catalogue in our existing repository. Preserve the ModuleLab production Worker. Add tests and training documentation. Create a pull request; do not merge or deploy until I approve.

## Checklist
- [ ] Feature is described in plain language
- [ ] Acceptance criteria are observable
- [ ] GitHub branch and PR are linked
- [ ] Tests and limitations are reported accurately
- [ ] Privacy and permissions are reviewed
- [ ] User approves any production change
