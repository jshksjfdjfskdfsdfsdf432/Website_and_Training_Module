## Upload from VS Code
1. Download ModuleLab_Training_Presentations_00-04.zip from ChatGPT.
2. Extract it; copy the **slides** directory into your local repository's **website/** folder, preserving filenames.
3. In VS Code, create or check out branch feature/module-pptx-downloads and pull the latest changes.
4. Stage the five PPTX files, commit, and push to GitHub.
5. Review and merge the pull request only after confirming all five binaries are present on the branch.
6. Wait for Cloudflare Ready and verify each module's Download PowerPoint link.
