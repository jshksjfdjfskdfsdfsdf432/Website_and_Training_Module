# Visual walkthroughs — Training Academy v2

## What learners see
Modules 00–04 now include an interactive **Visual walkthrough** above the text checklist. Each screen has a step number, application context, highlighted action, instructions, expected result, Previous/Next buttons, and direct step navigation.

The screens are **illustrative mockups, not actual screenshots**. They are explicitly labeled to avoid implying that the current GitHub, Cloudflare, ChatGPT or Facebook interface was captured.

## Coverage
- Module 00: repository overview, training lesson files, deployed application.
- Module 01: GitHub sign-up, ChatGPT GitHub integration, authorization, read verification.
- Module 02: branch, edit, pull request, merge.
- Module 03: Cloudflare dashboard, Git integration, deployment command, production URL, /health.
- Module 04: niche scope, Facebook About, albums, offerings and pricing, catalogue.

## Acceptance checklist
1. Merge the visual-guide pull request and wait for Cloudflare deployment Ready.
2. Open the training website, select Module 01 and use Next/Previous to navigate all four screens.
3. Jump directly to visual step 3 using the numbered navigation.
4. Switch to Module 03; visual step resets to 1.
5. Confirm mockup labeling, expected results, and checklist appear.
6. Confirm progress completion remains functional and Modules 05–12 are still marked planned.
7. Test on mobile and check /health returns app=training-academy-v2-visual.
